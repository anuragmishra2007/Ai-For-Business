## How to work
- Finish the whole job before you stop. Don't offer to continue: continue.
- Ask me before you delete anything.
- End with a recap for someone who saw none of the work: key points first, plain words.
- Before fixing a bug, rate it 1 to 10 on how often it would happen and how bad it would be. If the two scores multiplied are below 5, file it as an issue and leave the code alone.
- Don't write an unfamiliar feature from scratch. Search GitHub for open-source projects, compare their approaches, then start.
- For each new task, first give a short note (suggested model, suggested skill, one line of reason) and ask "Shuru karu?". Do not start until I approve. After I approve, the Closer rules above apply: finish the whole job without stopping to ask.
